## Phase 6 — anti-reverse-engineering, anti-phishing, security review (2026-10-24)
Version bumped to 1.3 (code 4) in build.gradle.kts and iosApp/project.yml (1.2 was the mid-phase checkpoint). Full write-up with severities, fixes and tests: SECURITY_REVIEW.md (rounds 1 and 2).
- Android release: R8 minify + resource shrink, `-repackageclasses`, all `Log`/`println`/`printStackTrace` stripped,
  `DebugGate.enabled()` pinned false via `-assumevalues` (fake order server, `spendsense://debug` links gone from the
  dex; debug intent filter + cleartext config only in `src/debug`).
- Anti-tamper: `security/SignatureCheck.kt` compares the APK signer SHA-256 with `BuildConfig.EXPECTED_CERT_SHA256`
  (release only; value `RELEASE_CERT_SHA256` in app/build.gradle.kts =
  adf4b21eb88f680422f6679ba10adc87435a8a03bb3514c8110b5b95c79c9fc7). Mismatch → `AppIntegrity.markTampered()`,
  storage never opens, `NotGenuineScreen`. If the release key ever changes, update that constant first.
- iOS: Release strips symbols (project.yml configs.Release), dSYM never in the IPA, `build-ipa.sh` refuses unstripped
  binaries; app-switcher `PrivacyCover`; first-run safety screen (`FirstRunSafety`).
- Anti-phishing: `ScamWarningCard` on Android setup, iOS first run, Settings › About.
- OTP: `ingest/OtpClassifier` (EN + Hinglish) applied in parser, ingestor, repository, AI ask/tools/statement AI.
- Hardening: exact OAuth redirect check + duplicate-param rejection, MCP guard vocabulary + homoglyph folding,
  `TextSafety.bound` against regex DoS, share-import content:// only + bounded reads, LIKE escaping, iOS
  `PopupQueue` cap, dedupe fix for re-posted notifications.
- Tests: JVM stress (`shared/src/androidUnitTest/.../stress`, sqlite-jdbc), iOS `IosStressTest`, `ParserFuzzTest`,
  `SecurityHardeningTest`, `OtpClassifierTest`, app `SignatureCheckTest`, `ShareImportUriTest`.
- Hardening, round 2: the MCP guard requires a leading read verb; OAuth issuer/resource metadata is cross-checked; the
  AI statement prompt treats statement text as untrusted and caps rows; account digits sent to the AI are cut to 4;
  more OTP formats are caught; CategoryGuesser no longer uses regex (iOS ingest ~9x faster).
- Tests at end of phase: JVM 491 (shared 479 + app 12), iOS sim 459, all green.
- Dist: ~/spendsense-dist/SpendSense.apk = v1.3 (code 4) release, sha256 a68ba190…fdf1a. IPA not rebuilt in this
  phase; the next feature build does both.
